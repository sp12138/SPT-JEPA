# State-dependent output basis: conditional prototype

Let p=f_old(u,a) be the existing carry prediction and δ=p−u, reshaped64×16. The optional output is p+M(u,pos)δ. Each target row of M comes from the same18→64→64 MLP on its16 local state values and fixed row-major grid(x,y) in[−1,1], with tanh hidden activation. The second affine layer starts at exactly zero, with private CPU initialization and no extra random draws in forward. Static control replaces the16 state inputs by zero; identical head parameters/operations, but1024 first-layer weights are permanently inactive. Both add5376 trainable parameters; extra arithmetic is401408 MACs per predicted state plus4096 tanh values and a64×64 matrix. Actual throughput is untested.

If M is static, A=I+M⊗I16 is fixed. With the verified old increment c+Vh, every endpoint remains u0+kAc+range(AV), of rank≤191. This static arm is a reparameterization of a fixed output basis. If M changes with current state, there is no such fixed global span. **At a fixed current state, instantaneous action-dependent increments still have rank≤191**; no single-step full-rank or arbitrary dynamics claim follows.

Constructive escape under the actual shared row architecture: let the old increment have only channel0, identical in every slot. Configure two hidden units so M_i0=tanh(u_i0+x_i)−tanh(x_i), all other matrix columns zero. Starting u0=0, the first increment a produces a·v because M(0)=0. The second increment b adds slot-dependent b[tanh(a+x_i)−tanh(x_i)], which is not proportional to v for different x_i. Thus a two-step reachable curve can leave its initial fixed one-dimensional span. This is not absorbable into one fixed W for all states; it does not prove useful physical control. Finite fixed head weights bound M because hidden tanh is bounded, and old LayerNorm bounds its raw output increment; there is no contraction or performance guarantee.

A stronger global counterexample distinguishes fixed191D versus state-dependent bases, rather than merely rotating one initial direction. Set M_i0=tanh(u_i0), all other columns zero, realizable by one shared hidden unit. Let old δ range over16 channel bases at slot0. For64 current states with only slot i/channel0=1, each channel produces increments e_(0,c)+t e_(i,c), t=tanh(1). The64×64 coefficient matrix has determinant(1+t)t^63≠0; the16 disjoint channel blocks therefore span1024 dimensions, versus16 for the same static head. This cannot be absorbed by any fixedrank≤193 output map globally. These synthetic states need not lie on the real encoder image manifold or one physically reachable trajectory; the separate two-step witness proves only escape from an initial span, not full1024D reachability from one initial state.

Zero output initialization makes the optional correction zero and preserves every original parameter, loss and gradient at initialization. Fresh old output_proj is also zero, so δ=0 initially: the new head gets no initial gradient. After the first old-output update, new output weights/bias receive gradients; after their update, new input weights/bias can learn. This delay is explicitly tested, not hidden by manually opening zero gates. Static state-input columns remain inactive. p−u is computed inFP32, but cannot restore a sub-ULP increment already rounded away by native carry addition.

Integration is only `SpatialCarrierLeWM(spatial_readout_mode='none'|'static'|'state')`; default none preserves the current frozen0c default/raw-chart paths. Active modes require local fixed carrier, identity basis and no chart. Model-visible states, goals, loss, noise, calibration, action input, renderer and native Trainer/checkpoints remain the existing interfaces. New prefix is `dynamic_readout_module`. No future observation enters the head: it uses the same per-time state already supplied to the old causal predictor.

This is a mechanism test using established dynamic parameter generation, **not a novelty claim**. [Dynamic Filter Networks](https://arxiv.org/abs/1605.09673) already generates input-conditioned, potentially position-specific filtering and applies it recurrently to video prediction. [HyperNetworks](https://arxiv.org/abs/1609.09106) already learns networks that generate other networks' weights, including recurrent weights. Here the narrow motivation is the measured fixed global output-span restriction of this local1024 baseline, with an exact zero-init and static matched-head control. Existing evidence does not establish that removing the restriction improves planning, especially after the train-only191D PCA yardstick failed to beat the learned subspace on held-out clips.

Scope: implementation plus CPU algebra/native-regression/gradient/checkpoint contracts only. No commit or GPU campaign until root review; no changes to running frozen0c source.
