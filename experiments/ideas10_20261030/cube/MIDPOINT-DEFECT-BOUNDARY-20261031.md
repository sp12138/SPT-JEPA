# 一条未排除但暂不推进的机制：真实动作中点缺陷

2026-10-31，只读已有报告与主文献。未运行模型、拟合、模拟器、训练或新评测；不计为原创idea，不实现。

**判断：保留“平均预测可能忽略非线性交互响应”这一可证伪假说；拒绝把下面的有限差分损失作为当前的新算法候选。** 它尚无直接机制证据，需要新增真实分支数据，且核心数学属于已有二阶Sobolev训练。它也不能解决已证实的目标度量与物理任务不对齐。

已有证据没有推导出“只需更准确预测”：Cube固定池中TF预测→真实编码成本rank很高，但真实编码selector仍可能选错物理目标。共同相关CEM让TF12k的primary均值20→33%、fresh15→31%，说明搜索分布是一个可干预限制；不等于已定位到预测曲率。最新hybrid600也没有跨任务赢家。因此下面只针对尚未核验的条件性机制，不把其动机当成结论。

## 具体操作与sample-level形式

一个训练单位是同一允许初始历史h下的三条**实际执行**轨迹。选两条普通、合法的记录动作序列A−、A+，令A0=(A−+A+)/2，分别实际执行得到x−、x0、x+。凸Box内的命令中点仍合法，但其物理后果完全不假设为线性；必须观察。三者均不是最优动作标签。初始状态重置/复现能力、额外交互和RGB曝光是额外资源，必须明示。

以固定编码器E隔离预测机制，令zj=E(xj)、ẑj=Fθ(h,Aj)、ej=ẑj−zj。保留原sample-level TF目标，概念上只加一个固定权重项：

    Lnew = (LTF(τ−)+LTF(τ0)+LTF(τ+))/3
           + ||e−−2e0+e+||²/(6d).

d为原状态宽度，状态单位/归一化保持原样；系数固定1，不能按任务找系数。一个minibatch只是独立三分支单位的平均；没有跨无关样本耦合。这里是额外预测约束，不宣称原TF的KL或ELBO推导自动包含它。部署模型、GoalMSE和CEM可以不变。

它要求预测真实的“中点后果与两端后果均值之间的偏差”，而非让所有动作扰动不改变结果。若末端响应为r(A)=r0+BA，有限差分严格为0。简单接触例r(a)=a、b(a)=max(0,a)，a=−h,0,+h给出Δ²r=0、Δ²b=h，额外项可以只暴露接触非线性。这是纸面构造，不是对真实Cube的验证。

## 为什么不能据此声称新信息、接触发现或正确goal metric

1. **损失没有新增标签信息。** 同一批三分支误差满足||e−−2e0+e+||²≤6Σj||ej||²；三个端点都准确时额外项自动为0。它改变有限容量/优化阶段的误差权重，不是凭空增加可辨识信息。普通TF在同一新增分支数据上可能已经获得全部收益。
2. **视觉曲率不等于物理交互曲率。** 即使物理运动r(a)=a完全线性，编码φ(r)=r²也给出Δ²φ=2h²；移动图像边缘、遮挡和ViT非线性都可能产生这种现象。机械臂本身可以继续支配该目标。冻结E只防止训练主动改坐标作弊，不能消除已有视觉曲率。
3. **不解决目标语义识别。** 预测非线性后果更准，不保证“物块已到位而手位不同”比“手到位而物块错误”距离更小。两个任务可共享完全相同的动力学/图像/目标图，却分别评价手或物块；无额外目标信息不能普遍辨别这个选择。
4. **数据缺口实质存在。** 现offline训练集没有同一起点的A−/A0/A+三分支；旧validation39候选池不能用于训练。不能把未执行的中点动作沿用原future当标签。真实世界不提供免费精确重置；隐藏状态或随机性会增加有限差分噪声。独立环境噪声下差分仍可估计条件均值差，但有限样本方差可能很高。

## 与旧方案和主文献的实质关系

- 旧I09辨认哪个动作发生；D5比较动作排列AB/BA；本项比较动作幅值中点后果。操作不同，但不能据此证明公开新颖性。旧D3是目标方向regret校正，本项不是部署成本校正；也不具备D3以外的新物理目标保证。
- **[Sobolev Training，Czarnecki等](https://arxiv.org/abs/1706.04859)** 已把目标的一阶、二阶导数及随机投影纳入训练。这里是用真实三次执行获得有限尺度二阶差分的应用实例。不能把“拟合曲率”或“更适合优化”改名为原创机制。
- **[Online/Adversarial World Modeling，Parthasarathy等，LeCun署名](https://arxiv.org/html/2512.09929v1)** 的Online WM已经执行planner提出的轨迹、使用真实后果扩展训练集；这是新增交互覆盖的直接对照。其AWM Eq7将受扰动state/action回归原future，施加局部不变性偏好。本项用三条实际后果匹配非线性响应，不把扰动视为标签保持变换；这个区别有意义，但不克服Sobolev先例。
- **[Monotone Cost Ranking，Chahe等](https://arxiv.org/html/2608.09073v1)** 按dead-reckoned轨迹相对示范的偏离排序受扰动作。这里不声称更偏离记录动作就更差，不规定动作间最优排序，只学习实际后果缺陷。这避免一种错误监督假设，却仍不自动得到正确物理任务距离。

## 若未来重新审议，最短必要对照与否定条件

先应单独审议新增训练交互的必要性，并冻结训练初态、分支构造和采集预算；它不属于当前已选定的离线短门范围。所有比较模型获得**同一完整三分支数据、相同RGB曝光和训练预算**；最小对照是普通TF与TF+上述缺陷项，固定E/状态宽度/原生规划，保留两任务两个seed。若只与没有新增分支的旧TF比较，就不能分离数据覆盖与损失机制。

机制门必须看未参与拟合的训练来源分支：真实缺陷是否有可预测信号，额外约束是否改善其预测，并在不牺牲普通响应的情况下改善独立闭环任务。若仅端点MSE/rank改善、argmin物理效果不变，或普通TF在同数据上获得相同收益，即否定该额外损失的价值。若缺陷主要来自机械臂视觉非线性，同样不应继续。

**当前结论：不实现，不启动新sim/训练，不训练旧validation池，不计原创idea。** 这份记录只保留一个可证伪机制及其失败边界；根据信息与新颖性门槛，尚不值得抢占下一短门预算。
