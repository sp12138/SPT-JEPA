# Second independent design pass, before targeted prior search

2026-10-30. Two new axes, not revisions of D1–D4. These are proposals to audit, not assertions of originality.

## D5: action-order defects as an observable interaction target

Failure: identifying which action happened can be solved by the robot's direct motion. It need not encode the obstacle/contact configuration that changes how actions compose. Construct two bounded action words AB and BA from the same initial state, with the same action multiset and duration. Their observed endpoint difference cancels any purely additive, state-independent action response. Learn that *observed order defect* directly, in addition to ordinary outcome prediction:

    w(x,A,B) = phi(x_AB) - phi(x_BA)
    L_order = ||D(F_B(F_A(E(x)))) - D(F_A(F_B(E(x)))) - w||².

phi is a fixed addressed image-feature map, not a physical coordinate label; D predicts that same observation family. The two branch outcomes must be actually executed, not generated by the current model. One paired fork is one sample-level training unit. No action is labeled optimal. The baseline gets the same branch data, and branch collection is charged.

For smooth vector fields f and g, the two small-duration compositions differ at second order by their Lie bracket (up to sign convention), whereas individual responses are first order. For constant translational fields the defect is exactly zero. At a wall or contact event it can reveal state-dependent interaction. This is distinct from old I09's action-label discrimination: swapping the order preserves the bag of actions, and the target is a quantitative observation difference, not branch ID.

Limit: free articulated motion can itself be noncommutative, contact can commute, and many small-step defects are extremely small/noisy. Hence it does not prove object-vs-effector semantic separation. A representation containing only the defect aliases all free positions; ordinary state prediction/grounding must remain. Exact same-state branching needs simulator reset or reproducible physical reset, and is not automatically available from a passive dataset.

Constructible toy: clipped translation on [0,1]. At x=.95, words (+.1,-.1) and (-.1,+.1) end at .9 and .95, defect -.05. At x=.5 both end at .5. A model that knows the commanded action sum but not boundary context cannot fit both. An actuator-only rotational example will test the counterclaim that a nonzero defect necessarily identifies external objects.

## D6: conditional history information in an observation fibre

Failure: the same instantaneous rendered configuration can have different velocities/contact histories, producing different futures under identical actions. A deterministic frame-only state cannot distinguish them regardless of representation width. For x_next=x+v+a with v=±1 equally likely and current x=0, its minimum squared prediction risk is1; one bit of history resolves it. This is different from merely retaining a longer rollout of the same insufficient state.

Separate an observable state e=E(x_t) from a history innovation m~q(m|H_t). The present-frame decoder is structurally D(e), with no m input; future observation prediction is D(F_e(e,m,A)). Price only history information unavailable in the current observation through

    L = observation/forecast likelihood + beta KL(q(m|H_t)||p(m|x_t)).

Goal images specify e_g, while the current hidden memory is inferred from actual history. The target goal does not specify an arbitrary hidden memory value. This is an observation-defined fibre, unlike D4's semantic action orbit. Under ideal log scoring, the full-history predictor's improvement over the frame-only predictor is I(Y_future;H_t|x_t,A); conditional bottleneck rate can quantify the history bits needed.

Potential distinction from old I08: I08 carries semantic state instead of regenerating/re-encoding images; D6 separates present-observable and history-only uncertainty, and the rate prior is conditioned on the current observation. However this may already be a conditional-information-bottleneck/state-space-model construction; literature audit may reject it as insufficiently original. It also does not repair TwoRoom's measured loss of *visible* position by itself, nor does it remove visible hand pose from Cube goal semantics. Extra history is an extra observation input and must be supplied to all baselines in a matched comparison.

CPU feasibility check: on frozen Cube executed trajectories, compare case-held-out prediction from current full qpos plus future recorded actions to the same predictor with finite-difference history. Physical states are diagnostic only and are not the proposed model's training labels. This can falsify the practical importance of hidden velocity at the measured horizon; it cannot establish an image-model gain.
