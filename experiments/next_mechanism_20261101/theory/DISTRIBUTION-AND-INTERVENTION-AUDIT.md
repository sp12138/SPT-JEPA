# 未来分布、逆向可达性与真实动作分叉：有界审查

2026-11-01。只读已有准入记录、六项主文献与标准库 CPU 精确见证；没有模型调用、数据采集、训练或 GPU。新监控和旧作业均未恢复。

**结论：本轮没有准入一个完整的新分布式规划机制。** 分布预测有真实优势，但“用逆向概率代替 Euclidean goal cost”目前既有明确错误版本，也有退回标准前向概率的正确版本；尚未提出一个额外操作，证明当前有限模型能够从这种分解受益。这不否认已知部件组合的研究价值。相比增加三个密度模型，真实受控动作分叉更直接补充已有数据无法识别的方向；需要和同分叉数据、普通预测损失作对照，不能把新增数据价值归给差分公式。

## 唯一审查候选：用 proper likelihood 学逆向支持，再作概率规划

在固定观测空间中记训练三元组为 `(S,A,Y)`，S 可包含允许的历史，A 仅为录制动作。拟合

\[
L=-\log b_\theta(S\mid Y,A)-\log r_\eta(S\mid A)-\log m_\xi(Y\mid A).
\]

每项只用该三元组，无 minibatch 统计或最优动作标签。对固定条件 C，log score 满足
`E[-log q(Y|C)] = H(P(.|C)) + KL(P(.|C)||q(.|C))`，因此在正确模型类、足够覆盖及优化到全局时是严格 proper 的。连续变量须明确参考测度；图像目标可用原始离散像素，不能任意学习一个会收缩的 target code 后仍沿用上述固定分布证明。

最诱人的规划量是 `b(S|g,A)/r(S|A)`，希望去掉初态占据率，仅保留逆向可达性。但 Bayes 给出

\[
\frac{b(S\mid g,A)}{r(S\mid A)}
=\frac{P(g\mid S,A)}{P(g\mid A)}.
\]

分母随候选 A 改变，**这不是按成功概率排序**。精确 CPU 联合分布中，两个动作成功率为 `[.8,.2]`，目标边缘频率为 `[.9,.05]`，该比值为 `[.8889,4]`，错误选择第二个动作。连动作与初态独立也不能避免它。

乘回 `m(g|A)` 可恢复正确概率；或学 `b(S,A|g)/P(S,A)`，其目标边缘分母与候选动作无关。这两个正确版本在理想解处是前向概率规划。**等价不意味着计算价值为零**：反向因子也许更容易拟合，或能改善有限容量梯度；但这需要实际给出便宜、稳定的分解及同预算证据，本轮尚无。独立拟合三项还可能不满足同一联合分布，乘除所得函数未必在 Y 上归一，低密度分母会放大估计误差。用一致联合模型可以修复，代价是边缘化计算，不能藏在“一个新 cost”之下。

完整规划应以预先定义的观测目标集合 G 为对象，最小化 `-log P(Y in G | S,do(A))`；连续目标单点的概率为零，density 与 tolerance mass 不同。单张全图不能识别“物块重要、手位不重要”的未知任务语义。给 G 加对象标签会越出本提案；固定图像邻域则保留原来未解决的视觉相似性选择。

## 有利性质与两个不可跳过的边界

**分布确有作用。** 目标0、容差.1：动作一产生±1各半，动作二恒为.05。预测均值的目标MSE为 `[0,.0025]`，选择从不到达的动作一；真实目标质量为 `[0,1]`。这支持保留多模态分布，但不能据此把普通概率世界模型重新命名为创新。

**录制未来动作不总等于干预指令。** 令中途随机位 W 为0/1各半，行为策略之后取 `A=W`，末态 `Y=W` 且完全不受动作影响。则录制数据的 `P(Y=1|A)` 为 `[0,1]`，实际 `P(Y=1|do(A))` 为 `[.5,.5]`。直接以整段闭环未来动作作为条件作 proper endpoint likelihood，仍可学对观察分布而学错干预。由充分 Markov 状态上的一步转移核、按外部指定动作组合，可以避免这个特定问题；有限图像历史、支持缺失与隐藏混杂仍须单独验证。

**proper 不等于训练路径已畅通。** 如果 target code 也可丢信息，或 renderer 能通过 anchor/noised target 绕过状态，proper 的观测预测并不强制规划状态保留目标变量。新增 backward 分支也不自动打通真实行动条件 forecast。必须分开报告状态使用、动作干预敏感性、真实概率校准和任务结果。

## 对 root 受控动作 secant 方案的窄结论

CPU 构造 `Y=S+B A`，旧录制动作都在第一坐标。矩阵
`B1=[[1,0],[0,1]]` 与 `B2=[[1,2],[0,-1]]` 在全部21条旧记录上完全相同。实际从同初态执行 `(0,+.2)` 与 `(0,-.2)` 后，结果差分别为 `(0,.4)` 与 `(.8,-.4)`：**新分叉真的消除了该方向的不可辨识性**。但在已测动作0、±δ处均为零的扰动 `c*a*(a²−δ²)` 仍可改变两点之间的动力学；单对分叉不能识别全局导数/接触规律。

用固定观测测量 ψ、模型的因果预测 `fθ(S,A)`，响应监督可写为

\[
L_{sec}=\|[f_\theta(S,A_+)-f_\theta(S,A_-)]-[\psi(Y_+)-\psi(Y_-)]\|^2.
\]

它是一个 paired interaction unit 的 sample-level loss，监督条件响应均值；若两次环境随机性独立，其差的分布并不是同一外生噪声下的个体因果效应。对应误差满足精确恒等式
`||e+−e−||² = 2(||e+||²+||e−||²)−||e++e−||²`。
所以它抑制共同误差、强调作用差异，**不凭差分创造新标签**；没有 ordinary point loss 时，共同偏置任意。若用可学习 ψ，则还存在双侧同时塌缩。预测器初始化为动作无关 carry 时，encoder 梯度可能相消；输出头梯度是否打开取决于动作条件 hidden features 是否实际不同，不能用全局梯度非零替代检查。

最小可证伪控制是相同新分叉、相同暴露/预算下，普通点预测与点预测+上述 secant；先在未参与采样的分叉检验真实差分幅度/方向，再看原 primary/fresh 任务。若只比旧数据 baseline 赢，不能归因新学习算子。决策排序不确定性选样可与 OnlineWM 的误差难度选样区分，但模型 ensemble 共同偏差会给出虚假低不确定性；这不是已验证的额外算法。
