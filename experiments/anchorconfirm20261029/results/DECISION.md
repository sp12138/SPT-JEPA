# Anchor 初筛的规划正面信号未通过确认

全部 120 项确认端点退出码为 0；12 个训练复跑的完整/便携检查点检查均通过。没有将训练延长到 600 新增更新以外。

| 方法相对原版 | 初筛变化，种子 1/2/3/4（百分点） | 新案例变化 | 相同初始完整状态的训练复跑变化 |
| --- | --- | --- | --- |
| Drop25 | +4 / +3 / +5 / 0 | −2.67 / +3.33 / −1.33 / +1.33 | −5 / +2 / +2 / +1 |
| Context mask | +1 / −1 / +4 / +2 | −2 / +4.67 / −0.67 / +4 | −5 / −1 / +1 / +3 |

Drop25 的四种子平均收益从初筛的 +3.0 个百分点，降到新案例的 +0.17、训练复跑的 0。Context mask 的收益从 +1.5，变为新案例 +1.5、训练复跑 −0.5，种子方向仍混合。所有逐种子新案例和复跑配对 95% 区间均包含 0；这些区间只描述固定权重下的评测不确定性。

新评测种子 1042/1043/1044 的 150 次查询中，有 1 个与初筛完全相同的 episode/start 查询。报告额外排除它，对 149 个查询重算；不改变结论。相同初始状态/RNG 的训练复跑用于量化数值轨迹变化，不是新的独立训练种子。

Drop25 的物块角度线性 probe R² 在四个种子上略升，约 +0.013/+0.007/+0.003/+0.005；agent R² 略降。这是局部表示指标的探索性点估计，不证明 anchor 侧信息假设已得到因果验证，也不等于规划改善。

决定：不把 Drop25 或 Context mask 宣称为更好的算法，不根据当前证据延长这一组训练。保留初筛与确认的完整逐例结果和图，避免只报告正面筛选结果。

当前仍没有新算法在同规模、匹配预算下证明稳定优于原版 AS-JEPA。此前选出的 lower-beta 和 temporal-forecast 两条方向正在完成第二 epoch 的匹配任务评测；lower-beta 属于原算法调参。
