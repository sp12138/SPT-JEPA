# Raw public state interface for the shared local chart

Status: six new CPU contracts and four legacy numeric contracts passed. Root subsequently authorized four batch128 native two-step GPU preflights on dev13 GPUs0–3, after immutable commit/source preparation and actual slot checks. A four-run600 plan remains candidate-only until root reviews all eight preflight endpoints. This is a coordinate-consistency control using established invertible-map mathematics, not a novelty or performance claim.

The sole new switch is `spatial_state_interface="raw"`, with the existing `spatial_chart="identity"` or `"bounded"`. The default remains `"chart"`; old configurations and checkpoints keep their existing behavior and keys. The fixed local measurement, original 128-frame calibration, 64 slots × 16 channels, 2,128 shared chart parameters, native objective, data, optimizer/schedule and planner are unchanged.

The public `encode` state is the normalized fixed carrier u. The public `predict` computes T(input history), calls the original predictor including its original carry addition, and returns the differentiable inverse of its output. Thus the unchanged RobustLeWM posterior noise, rho=.8 AR conditional target, entry rate, surprise rate, forecast mixture, clean rollout and GoalMSE all remain in raw coordinates. The chart is inside the finite network parameterization. It cannot lower the raw-coordinate rate by a pure coordinate contraction that leaves raw predictions unchanged.

An explicit `RawConditionChartRenderer` subclass transforms raw conditions exactly once at `forward`, including direct health calls, flow loss, generation, flattened or slot-shaped conditions, and condition-drop calls; None remains None. It uses no interception hook. The shared chart is registered only at `carrier_chart_module.*`; a nonregistered object reference in the renderer points to that same owned module. Base construction uses a default-preserving renderer class factory. No renderer tensor is renamed and no chart parameters are duplicated in the optimizer/checkpoint.

The historical no-grad inverse remains untouched. The new inverse solves the contractive fixed point and supplies a first-order implicit backward. For T(v)=v+g(v), Lip(g)≤.5, a measured residual r gives exact-real solution error ≤2||r||. Forward acceptance requires this per-slot bound to be ≤1e-6+1e-6||target||; the backward adjoint uses relative tolerance 1e-6 with **zero absolute floor**, so small training gradients are not dismissed. Both solves stop within 64 iterations or raise; nonfinite values also raise. Matrix bounds use the existing full-SVD normalization. The mathematical certificate is exact-real; floating-point residuals and gradients must be checked against a higher-precision oracle. It is not a global floating-point proof.

The implicit backward includes input and explicit chart-parameter derivatives, followed by autograd through effective matrix normalization. It retains one solution rather than the full iteration tape. It still adds chart evaluations, inverse/adjoint iterations, norm computations and synchronization for residual checks; equal CEM sample budgets therefore do not imply equal FLOPs/latency. CPU tests are not a GPU memory or throughput validation. Double backward and higher-order/forward-mode transforms are unsupported; native first-order training is the supported contract.

At exact initialization the predictor is identity carry and the DiT output is zero. The chart's first loss gradient can cancel exactly; this is expected. A small CPU semantic check uses the native loss with a reduced-depth model and two SGD updates at .01, records the first gradient and verifies a nonzero finite chart gradient after an original-network update. This is deliberately not the native scheduled optimizer/preflight or a learning result. It does not require the first chart gradient to be positive.

Required CPU evidence: native identity loss, all metrics, original gradients and RNG exactly match the historical local default; the legacy nonidentity chart path remains exact; all 553 old tensors and checkpoint keys are preserved; inverse values and all input/parameter gradients match an independently differentiated double-precision fixed-point oracle and directional finite differences; inverse composition cancels chart gradients; solver failures and higher-order use fail explicitly; nonlinear conjugacy covers the native rho/forecast mixture for both one-step and forecast rate priors; every renderer entry path transforms consistently. The conjugacy test injects explicitly conjugated analytic predictor/decoder test doubles into the unchanged native loss; it does not assert that the actual finite networks are automatically conjugate. The tests use no physical labels or new calibration.
