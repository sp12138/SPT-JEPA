# RoboCasa Reach 同时间比较

本轮已转入独立动作读出短程验证，当前状态见`HANDOFF.md`和
`experiments/robocasa_action_probe/PROTOCOL.md`。旧controller在当前完整
子阶段后退役；以下是原比较协议，不是恢复无限期训练的指令。

最新用户授权持续运行至叫停，每累计训练一小时评测。dev13：公开
RoboJEPA300M 架构的 RGB-only K2 适配；dev15：SPT global16空间初态
上下文；dev6：原64维temporal-forecast。用户已排除dev6-2c，grid16仅
保留历史数据，不再连接、恢复或调度。三算法均seed1，各一台8卡，不是独立种子重复，不能
宣称稳定性或把选择后的赢家当作未选择确认实验。

共同使用冻结的 V-JEPA2.1-G 编码器和普通随机命令转移日志：1120条训练、
96条验证，厨房分离；两视角、中心方形视野224、缓存196×1664 FP16特征。
预测器均随机初始化，不继承历史高分模型或公开动力学权重。只输入 RGB
与实际输入命令，不输入本体、奖励、成功或任务，不以任何动作作标签。
SPT 保留自身 sample-level 像素64 flow/rate 目标，无 inverse。global16
用16个全局query、256维代码和实际初态上下文；64维版用4个query且无
场景bridge；grid16用16个固定空间区域的query和初态上下文。分别检验
较优完整配方、紧凑的动态表示和有空间地址的表示；grid16当前仅为历史对照。历史源案例Reach回报
约91.88/86.10/84.35%，不是成功率，也不是本轮新头/新案例的性能保证。
grid16历史support代价约91.83%，本轮主要对照统一uniform L1，不混报。

基线复用公开24层、width1024预测器、官方 latent L1 和 detached K2：
TF/2+AR/4；状态 token 固定零，规范化14D命令补零到64D。这是共同数据
的受控适配，不是23数据集完整论文复现。SPT window8，基线window16；
global batch32、每模型8张H200。容量、每秒更新数及图像计算量不同，
必须同时报告；共同冻结编码器缓存成本不计入任何一方的训练时间。

训练时长累加最慢 rank 的数据读取、传输、前向、反向和优化器迭代墙钟。
初始化、存盘、评测另计；分配机器的总墙钟同时记录。双方共同900秒线性
warmup后恒定学习率，SPT非renderer5e-5/renderer1e-4及原生betas/WD；
基线AdamW5e-5、(.9,.95)、矩阵WD.1、bias/一维参数无WD。无限期运行
不安排任意终点的cosine衰减。恢复包含模型、优化器、时钟调度状态、
8rank RNG和确定性样本游标。

每小时8个固定案例：target厨房1/4/8/10，各task seed19301/19302；先固定
再运行，不筛选成绩。相同初态物理重放、目标RGB与严格图像检查。公开
CEM字节码与数学不改，仅省略无环张量状态的强制GC；1024候选、H1、
首轮15/后续10轮、top20、context2、execute1、5个真实动作、action_repeat1、
std/maxnorm .3、mean/std momentum .15/.70、双视角等权。每卡同时评测
一个独立案例，8张卡均分案例。报告轨迹平均归一化回报、最终距离、
2mm final/any完成率，不能把回报当成功率。新案例与旧四例不作配对涨幅。

先执行8个真实训练更新并保留到正式预算，验证有限梯度、完整恢复、
末尾无有效动作的污染不影响loss、公开K2数值一致和缓存重编码，再做
真实小规模规划入口。入口通过后持续训练，每小时评测；不恢复旧goal、
旧实验或LLM监控，不自动更换算法。报错保留并停在检查点，修复后按
完整状态续训。EFS根为`runs/robocasa_time_compare_20261112`，原始结果、
运行状态及检查点不进Git。

现有冻结训练worker继续逐小时输出各自结果，不因资源范围调整而重启。
当前三方法共同训练小时由独立`report.py --root <root> --output active-latest.json`
按需汇总，读取`plan.json`的`active_runs`；不增设后台监控。旧冻结worker
仍可能写入历史四方法`latest.json`，后续查看当前对照应使用三方法入口。

dev6在约9.57h出现实际BF16非有限梯度，原错误保留。数值恢复可对失败的
同一全局batch恢复外部RNG后用FP32重算一次；不能跳过样本或以非有限
梯度更新，FP32仍异常则停止。两次尝试耗时均计入训练时间。该精度路径
单独披露，不声称与旧AMP轨迹逐位一致；从完整检查点重放的未保存更新
也单列。其他正常训练保持原冻结运行源码。
