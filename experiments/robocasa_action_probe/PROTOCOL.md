# 独立动作读出短程验证

用户在原长训持续平台后建议：表示继续学习动作后果，stop-gradient后
单独训练动作头，以直接动作输出代替昂贵规划。先用已有检查点验证可行性，
不预先承诺成功。当前有限pilot使用dev13/dev15/dev6，不使用其他机器，
不恢复旧goal或LLM监控。

三条读出：共享冻结V-JEPA特征的全局均值（视觉对照）、17小时global16
表示、17小时64维表示。视觉对照不调用RoboJEPA预测器，不能把它称为
RoboJEPA策略复现。当前视觉编码器本身保持冻结，SPT的池化/adapter来自
后果学习；这不是已经完成原生从零或解冻大backbone的实验。

使用原普通随机命令日志1120train/96validation及同一厨房分离；只读取
RGB特征与commands。每个样本输入两个同一真实转移的RGB编码，标签为
这一次转移实际输入的a_t前三个平移坐标，不是a_{t+1}、最优动作、专家
策略或未来动作序列。所有表示先冻结并detach，动作头无法反传到后果
学习器。动作监督仅属于明确分离的读出阶段。

线性头为`W(E(next)-E(current))`，无截距，目标相同时输出严格为零。
拟合目标是样本MSE加L2参数正则，解析ridge求解，不使用批间表征正则。
正则强度固定候选1e-6/1e-4/1e-2/1，只按原验证厨房的动作RMSE选择，
不按目标厨房成绩选头。记录预测零动作的验证误差，检查读出是否有信息。
这比一般策略头更受限，失败不能推断所有独立动作头都无效。

控制时以目标RGB代替训练时的下一帧。该变化不保证有效：远目标、接触、
一对多逆映射或训练动作未实际实现，都可能导致误差。相同8个预固定
Reach案例、5动作、norm上限.3、RGB/物理重放与2mm规则；直接执行动作头，
不调用CEM。比较回报、距离、完成数及编码/读出/物理/整回合耗时，不能
把NN加速比例直接当整回合加速比例。案例已用于原规划开发，不是新确认集。

原三个长训controller在当前子阶段外暂停，待子阶段完整保存并退出后
退役controller，不杀正在训练的子进程、不删除或修改原检查点。有限
pilot先8卡分片提取表示，单头解析拟合，再8卡各跑一个案例，共24回合；
完成后HOLD，无自动长训、额外数据采集或搜索。

视觉对照原定dev13；该机当时刚进入下一小时的完整训练阶段。停止没有
子进程的待机probe后，视觉对照改由已完成global16的dev15顺序执行；
未重复运行任何头。dev13只保留有限的当前阶段退出交接，不再自动续训。
