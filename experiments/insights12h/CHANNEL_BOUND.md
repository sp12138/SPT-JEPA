The collapse check adds a direct signal-to-noise audit. If S=mu(X)+sigma0*N with independent standard Gaussian N, then I(X;S) <= 0.5*sum_i log(1+Var(mu_i)/sigma0^2), in nats, using a diagonal covariance upper bound. An observed mu std near 0.0007 at sigma0=0.1 gives only about 0.0016 nats for 64 dimensions. A low training flow loss or an unconditional mean that beats a distant anchor can therefore conceal a nearly information-free state. The empirical variance is measured on common held-out frames. After 8000 optimizer steps, stop an arm only if this bound is below 0.05 nats, permuting states changes generated pixels negligibly, and horizon-7 agent predictions do not materially beat copying. This is an exploratory early-stop rule, recorded separately from the original handoff's pose-ratio rule.
