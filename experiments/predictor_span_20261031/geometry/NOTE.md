# Coordinate learning and changing output directions have different limits

This is an analytical distinction between the two current prototypes, not a qualified new idea, a novelty claim or evidence of better planning. The empirical starting point is the existing local1024 output-space audit: a fixed checkpoint predicts increments in `c + range(V)`, with rank(V) at most191. A k-step prediction therefore lies in `u0 + k*c + range(V)`, irrespective of the nonlinear attention or action dependence used to choose coefficients inside that space.

An invertible observation chart can bend this restriction without removing it. In the raw-coordinate prototype, write z=T(u) and let the chart predictor retain the same carry and output layer. In exact arithmetic, every k-step raw endpoint lies in

`T^{-1}(T(u0) + k*c + range(V))`.

For a smooth invertible T, this is a smooth image of an affine space of dimension at most191. It can align much better with a curved physical observation manifold; that can be useful even when the physical state has far fewer than191 dimensions. It does not create unrestricted high-dimensional dynamics. Native action sequences need not commute: the coefficients inside V depend on state and history. The claim is about an invariant restriction on endpoints, not commutativity of the entire learned predictor. Across horizons, the affine offsets also involve c, so drift must not be silently dropped.

A state-dependent output matrix instead allows increments in `A(u)(c + range(V))`. At a fixed u, rank remains at most191. Across successive states, these spaces need not be images of one common fixed space under an invertible coordinate map. Composing actions can then produce a displacement outside the directions available initially. The relevant distinction is how changes compose along a trajectory, rather than how many coordinates the observation retains.

A finite example makes the difference precise without appealing to a dimension slogan. In three coordinates (x,y,z), let the two output directions be `(1,0,-y/2)` and `(0,1,x/2)`. Four steps with coefficients `(a,0),(0,b),(-a,0),(0,-b)` return x and y to their initial values but change z by `a*b`. The instantaneous output rank is two everywhere. The same coefficient loop in a fixed two-dimensional plane returns to the initial point, as does that fixed-plane process conjugated by any invertible chart. The accompanying CPU script checks both the plane and an explicitly curved chart at three nonzero configurations; maximum numerical error is below1e-14. This example concerns the general conditional-operator class. It is not a construction of the exact shared64x16 head or a proof of reachability on the real encoder manifold.

This clarifies what the actual experiments can establish. The raw chart tests whether a learned curved representation of the same constrained dynamics improves alignment under consistent noise/rate semantics. The dynamic readout tests whether changing the output directions with the state helps beyond a static matrix with the same nominal parameter count. Neither needs an optimal-action label or a batch-level loss. Neither follows as a successful algorithm from this geometry: at600 updates the dynamic head improves factual forecasts but has no consistent planning advantage. The existing cache also lacks the pre-correction increment, so it cannot verify that actual corrections leave the old space. That limitation remains explicit; there is no inferred measurement of missing tensors.

The practical hypothesis is narrower than “more expressive is better”: learn the action-dependent changes required by the task in observed coordinates, while preserving enough information to distinguish goals. The current output-space floor is one obstruction. Misleading goal distances, off-policy prediction errors and optimization can remain after it is removed. The planned2000-step paired comparison tests whether the demonstrated forecast improvement becomes a control improvement; no further theoretical argument substitutes for that result.
