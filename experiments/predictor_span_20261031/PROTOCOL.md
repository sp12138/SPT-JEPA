For output weight W, bias b, LayerNorm γ and β, let H=I−11ᵀ/192, V=W diag(γ)H and c=Wβ+b. Every increment has form c+Vh. Consequently a clean k-step endpoint is u0+k c+range(V), with rank(V)≤191. This is tighter than the relaxed u0+span(W,b) bound (rank≤193). The CPU audit checks both SVD ranks and the cached forecast residuals, using FP64 projections of stored FP32 arrays. Rank threshold is standard max(shape)×FP64 epsilon×largest singular value; no selected tolerance or validation tuning.

For actual target u_k, the necessary affine oracle error is ‖(I−P_V)(u_k−u0−k c)‖²/D. For teacher-forced one-step predictions replace u0 by u_(k−1) and k by1. Report raw oracle MSE, its fraction of actual prediction error and of true change/carry error, all seven horizons, and both seeds. Verify the Pythagorean split of prediction error into unreachable and in-span parts. Also retain the looser span(W,b) oracle and numerical forecast off-span residual. Equal observed local2000/6000 arrays and the basis Q rotation are checked directly.

The lower bound optimizes over arbitrary hidden vectors; real actions, attention, LayerNorm radius and dynamics may impose additional restrictions. A low-rank head can be harmless when changes lie in its subspace; the fixed CPU toy verifies this counterexample and a positive orthogonal lower bound. Neither rank nor latent error establishes planning causality. Cross-family raw MSE uses different representations, so ratios and dimensions accompany it. The64-dimensional controls may be full rank despite the same hidden width. Physical component decomposition is optional only if an already saved fixed readout is available; no new fitted probe is authorized.
