# Uniform stable-attachment public NGC control

This is a numerical variant of the public NGC baseline, not a learned method or an innovation claim. The official vendor files stay byte-identical. `StableNGCCost` overrides only `attach`: FP32 `torch.cdist(..., compute_mode='donot_use_mm_for_euclid_dist')`, followed by the original stable sort, 15th-neighbor radius, four anchors and strict positive-radius assertion. Inherited graph-route costs, direct candidate-goal distance, goal cache and dtype behavior are unchanged. Every one of the 12 models uses this same implementation.

Reuse the 10 successful original `graph.npz` files byte for byte. For the two failed TwoRoom TF models, construct the original FP64 mutual-15NN graph and component bridges from the saved exact 5,000-node recaptures. No RGB read, encoder, predictor, renderer, optimizer, simulator, new node selection or fit occurs. Derived graph reports bind original checkpoint, source, full state, cohort, node/graph and report hashes. Original 10 success / 2 failure records and all original 48 held evaluations remain intact.

The 12 CUDA gates cover every saved node and all 25 million ordered node pairs per model in chunks of 32. They compare direct FP32 to direct FP64 on the same promoted float32 coordinates, require finite positive radii and exact self-goal zero, and verify original graph symmetry, diagonal and component/bridge count. A dimension-derived `8*(D+4)*eps32` relative arithmetic-error bound is checked; it changes neither distances nor radii. The two TF gates also repeat the original CUDA-mm calculation and actual public `attach` assertion, so CPU and CUDA evidence remain separately named. No floor, centering, deduplication, resampling, parameter grid or fallback is allowed.

CPU checks rerun all nine existing native-controller and graph contracts with the stable attachment, plus independent extreme-common-offset, exact-duplicate rejection and inheritance checks. Native L2 returns the same tensor and exact CEM outputs; recorder calls add no model calls or random draws. L2 instrumentation now computes stable NGC scores too, so wall-clock timing is instrumented rather than a bare-L2 speed claim. CEM sample/iteration budget is unchanged.

The distance tolerance checks arithmetic accuracy, not bitwise or nearest-neighbor tie invariance. Passing the fixed-node gate does not certify every future predicted query: the inherited live radius and finite assertions remain active and any failure must stop its chain without fallback.

Create separate derived graph and evaluation roots, preserving candidate HOLD files before any reviewed activation. Slots stay within dev2 GPUs 3–7, dev13 GPUs 3–7 and dev15 GPUs 2–7. After all 12 graph gates pass, report to root before activating the new 48 paired evaluations: both tasks × both seeds × local1024 / raw native / TF × L2 / stable NGC × original primary / fresh 50 cases. Local1024 is used on both tasks; no F64 substitution, action covariance/projection, BN calibration, historical-best baseline or additional cases. Retain all contemporaneous L2 replays and the original command controller/settings.
