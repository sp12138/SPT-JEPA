# TwoRoom / Cube：从失败位置反推需要学习的对象

2026-10-30。本轮使用 dev2/dev13/dev15，保留全部历史实验，依次运行配对短训练、冻结表示诊断和模拟器反事实评测。训练仍只使用图像与已执行动作；物理坐标只训练冻结模型的诊断探针，不进入候选算法或部署策略。当前没有得到大幅超过 JEPA 基线的新算法。

## 先区分两种失败

TwoRoom 的编码器并非完全看不到位置。2000 步时，64维 QueryPool 的 agent xy 读出 R² 约 .11–.29，而相同输出维数的固定空间投影达到 .89–.96；后者在初始化时就已很强。问题至少涉及**状态聚合如何保留位置，以及后续预测器是否真正使用这种区别**。反复调整一个已有信息很弱的通道，并没有使它自行启动。

Cube 的问题更靠后。temporal-forecast 的预测代价与实际编码终点代价排序高度一致（.948/.951），但其目标距离主要跟随机械臂。控制物块位姿后的机械臂 partial rank 为 .928/.935；控制机械臂后的物块位置 partial rank 仅 .034/.022。LeWM 对应的物块位置关联更强。

不能因此宣称我们的 Cube 动力学普遍更准。共同非 oracle 候选上的物理读出揭示：temporal 的末端位置预测 R² 为 .977/.976，优于 LeWM 的 .855；物块位置预测 R² 为 .816/.772，低于 LeWM 的 .854。**它更擅长预测自己最强调的因素，且这个因素不完全等同于任务目标。** 这些是固定线性探针的结果；LeWM 与本模型的状态维数和训练暴露也不同，不能归因到单独一个训练目标。

## 干预排除了什么

- **当前残差由背景主导：不支持。** TwoRoom 约9.4%的运动像素占高噪声残差约84–91%。
- **主要是 rate 压力过大：未获一致支持。** fresh/resumed 配对600步 rate-off 没有稳定恢复 TwoRoom 状态；Cube 的状态幅度增加也未带来规划改善。
- **去掉状态噪声或强迫 DiT 从纯噪声学习即可恢复：当前门控不支持。** 两种改变及其组合均未明显改善位置读出；600步任务结果没有跨种子的稳定优势。600步仍在 warmup 内，不能据此证明永远无效。
- **Cube 只需减去机械臂的三个方向：不支持这种简单修复。** 投影确实消除了所拟合的线性映射，但重新拟合后机械臂 R² 仍超过 .994，非 oracle 候选成功率没有改善。它没有真正擦除机械臂语义。

完整证据：[信息](results/information/RESULTS.md)、[rate](results/rate-controls/RESULTS.md)、[通道](results/channels/RESULTS.md)、[空间读出](results/spatial/RESULTS.md)、[Cube候选](results/cube-audit/MECHANISM.md)、[度量干预](results/metric/RESULTS.md)。Cube候选实验只执行25步首计划，不能与50步闭环成功率混为一谈。

## 可以抽象出的本质

“好状态”必须相对于未来要回答的问题定义。这里有三个分别可能失败的要求：

1. **区分：** 状态能区分会影响未来的问题，例如 agent 在墙的哪一侧。
2. **转移：** 给定执行动作，预测器能正确更新这些区别。
3. **判断：** 给定目标，代价函数能按真正的任务进展排列候选动作。

生成损失较低、状态可被线性解码、latent rollout 较准，分别不能保证这三个要求同时成立。对任意可逆表示变换，信息和精确动力学都可以保留，欧氏目标距离却可能改变。例如把机械臂坐标放大 c 倍、物块坐标缩小 c 倍，欧氏距离便按 c² 与 c⁻² 加权。这只是说明“信息充分”与“几何合适”在逻辑上不同；并非声称 AS-JEPA 的固定噪声、rate 目标对这个变换保持不变。

对于条件去噪，状态的理想均方误差价值恰好是

\[
\mathbb E\|\mathbb E[V\mid U,Z]-\mathbb E[V\mid U]\|^2,
\]

其中 U 已含 noisy target、anchor 和时间。它奖励的是状态在这些辅助输入之外增加的预测能力。规划时没有目标的含噪副本，也不能假设 encoder 之外的分支替它保管初始位置。因此，**条件生成的有效信息分工，不必形成可独立用于控制的状态。** 这解释了为什么要检查分支到底在做什么，不能把 loss 改善直接当作 world model 改善。

这一抽象有预测状态表示、value equivalence 和 decision-metric alignment 的明确先例；它不是本轮发明的理论。[理论说明及原始文献](../hardtasks20261030/THEORY-STATE-QUERY-CONTRACTS-20261030.md)区分已有结果、严格恒等式和待验证假说。

## 空间分区是机制检验，不是创新宣称

新对照只改变四个 QueryPool 查询允许读取的 patch：完整图像、四个连续区域、四个等大小随机区域。三者参数、初始化、损失、数据和输出维数一致；每个查询都保留 CLS，ViT 自身仍然全局注意。

这里有一个可直接分析的退化极限：原版四个查询若都为零，且 query 投影偏置为零，四组注意力都是同一套均匀权重；它们经过共享 LayerNorm 和共享16维 head 后完全相同。名义64维状态便是同一个16维向量重复四次。实际查询初始化标准差为.02，并非这个精确极限，但模型需要靠学习把近似共享的聚合变成不同的读出。分区让不同查询即使为零也能读取不同地址。这解释了干预的作用位置；本轮尚未测量完整特征谱，不能据此断言实际有效秩就是16。

相同初始权重下，TwoRoom 连续分区的位置读出平均约 .87，随机分区约 .43，原版约 .21；位移读出也明显改善。它支持空间组织对信息可读性的作用。由于改善发生在训练前，必须另行检验训练后的噪声耐受、动作条件预测、状态使用与规划，不能把随机初始化的好探针称为学到了世界动力学。

八个同参数600步门控及16个初始/终点探针现已完成，完整结果见[空间分区干预](results/pooling/RESULTS.md)。50个相同验证案例的成功率如下；每格保留两个训练种子：

| 600步读出方式 | TwoRoom | Cube |
|---|---:|---:|
| 原版全局 | 6% / 8% | 14% / 10% |
| 连续空间分区 | 12% / 16% | 12% / 8% |
| 等大小随机分区 | 6% / 6% | 16% / 10% |

TwoRoom 的连续分区得到两个种子同向的 +6/+8 个百分点，相对随机分区也更好；对应配对新增/丢失成功为6/3和8/4，绝对数量仍小。Cube 未获改善。这提供了**空间组织在 TwoRoom 上有实际早期价值**的证据，不是跨任务的大幅胜出。

干净位置读出在600步仍约.86，但原sigma=.1下的探针无效；将真实状态改为常量也几乎不改变 DiT 的条件预测。这里必须区分两条路径：这些干预测的是**渲染器使用状态的程度**，latent CEM 使用干净状态、预测器和目标距离，并不经过 DiT。因此，不能据此称整个预测器或规划器不使用状态。早期规划增益可能通过干净 latent 的几何或动作排序发生，本轮尚未分离这两者。

这些结果还没有验证可推广的新算法；本轮全部短实验在门控处停止，完整状态、失败记录和冻结源码均保留。600步仍在学习率 warmup 内；“目前不值得据此直接跑长网格”和“更长训练必然无效”是不同结论。空间分区与无噪声状态的交互尚未测试，单因素阴性结果不能排除互补作用。

## 方法方向需要满足的标准

比继续堆 loss 权重更值得研究的是：让状态成为回答**有地址、跨时间、动作条件的观测查询**所必需的通道，并检验输出几何是否能承担目标比较。一个候选必须同时改善状态区别、动作预测和非 oracle 动作排序，才值得扩大预算；只提高 probe 或 latent 自洽性不够。

这仍是研究规范，尚非已经验证的新方法。单张全场景目标图本身也不能普遍说明哪些因素允许不同：同一图像既可表示“物块到此即可”，也可表示“连机械臂姿态也要一致”。训练数据、任务接口或明确约定需要提供这种语义，不能偷偷用评测标签补足后再称纯世界模型能力。

PushT 上 temporal-forecast 的已测优势仍成立；“其视觉变化、动作影响和任务几何更容易对齐”目前只是跨任务解释的假说。本轮没有对 PushT 做同样完整的分解，也没有完成同预算 LeWM 重训，因此不能把这句话当作已经证明的 A>B 原因。
