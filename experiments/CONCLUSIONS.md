# 关键结论

更新：2026-11-11。旧 MetaWorld 研究已结束；RoboCasa已进入10000步预算对照及官方参考逐组件诊断，尚无操纵突破，入口见 [HANDOFF](../HANDOFF.md)。资源授权为dev13/dev15/dev6/dev6-2c。较优配方与来源统一保存在 [best-configs.json](best-configs.json)，原始实验记录的定位见 [归档说明](../docs/experiment-archives.md)。这里的成绩均有适用边界，不是统一公开基准的 SOTA 声明。

## RoboCasa 的新证据

配对1000→10000步续训全部收齐8模型／64新增回合：V-JEPA-SPT的Reach平均进度11.03→47.58→64.77%（1000／5000／10000），own-SPT为17.32→23.93→15.73%。10000步own-dense／V-JEPA-dense为20.11／38.85%；四组Push均9.1%–9.3%，所有正式点严格完成均0。短预算确实遮蔽外部视觉骨干的收益，但续训也统一重启LR，不能仅归因于步数。四个物理源案例重复使用，未作目标厨房确认。新参考对照先保留官方dense动力学，分开检查图像预处理和SPT读出；公开主轨的本体输入与RGB mode2分开报告，不能把输入／embodiment差异当作算法优劣。缓存API验证成功不等于性能提升。

同源四案例的公开2B RGB对照为Reach77.19%、Push11.25%，严格成功0；square224为70.67／9.29，8B RGB为43.51／9.18。完整主输入的2B released proprio为92.02／28.33，native proprio为93.14／4.54，8B released为95.44／9.15；均严格成功0。模式2/3同时改变状态、embodiment和动作编码，不能单独归因于proprio。公开预训练／状态参考与RGB候选分轨，不能当同训练预算算法排名。

跨视角消息的六个11000步模型／24源回合已齐：plain／self／cross的Reach75.67／77.75／80.05%，Push9.20／9.19／9.17%，严格成功均0，不长训。保留公开2B动力学、只替换SPT目标读出的8回合为86.69／10.89，差于原92.02／28.33；额外读出适配数据和square→rectangular分布偏移须披露。终点／路径协方差采样的24物理回合也未支持CPU数值优势：公开2B Push原28.33%，Gaussian0%、endpoint1.72%；SPT仅一父模型单案例收益，不是稳健改进，无长训晋级。

固定抽8个TRAIN厨房、每个8条既有分支日志的1024步重放全部通过，物理／RGB／实测位移误差均0；16/64条有机器人接触、36/1024步有接触，8/8组物体跨动作XY位移差>1cm。数据并非完全没有对象交互，接触稀疏也不是已证明的唯一原因。3584同时间跨分支pair的固定距离统计中，dense V-JEPA物体XY／EEF秩相关为.122/.740，SPT约.090/.910；控制EEF后物体相关约.100/.054。没有固定EEF匹配pair，不能声称物体信息缺失或因果解释已成立。受保护状态只做诊断，不进入训练或proposal。同3584个pair的RGB224／64距离物体相关.117／.121、EEF相关.579／.580，未见明显分辨率退化；不能据此断言生成器保留了对象信息。

再续训5000步的六模型／24源回合全部收齐：plain／冻结表示／未来特征目标的Reach86.10／86.21／66.25%，Push9.21／9.20／9.26%，严格成功全0。固定表示与原10000步父模型读出精确一致，额外训练仍没有操作收益；全部最终完整状态恢复通过，不晋级长训。生成器诱导距离的八模型×四旧路径只读测试也未显示稳定改善；旧路径未让机器人回到目标姿态，因此这些排序不能单独证明对象表示缺失。

条件信息对照已否定当前实现的收益：解码器有初始RGB，给先验也加同一实际初始RGB，六模型各续训到20000步后，plain／pooled／spatial的Reach67.74／78.66／67.02%，Push9.17／9.16／9.18%，严格final／any全0。没有超过旧15000步plain的86.10% Reach，不长训。最优log-loss先验遗漏C的代价I(Z_future;C|历史,动作)是成立的理论动机，不保证有限NN受益；本轮也不能证明场景信息不重要。

普通闭合动作／反馈回位采集已完成192条TRAIN日志／3072真实转移，全部有效日志保留、0错误。固定盐64条诊断重放物理／RGB／实测位移精确；9/64有接触，12/1024步有接触，不能称为接触富集。匹配世界EEF≤1mm、完整旋转≤.004rad、夹爪≤.5mm后112对中有20对物体XY差>1cm，dense／两个15000步SPT的物体XY秩相关为.352／.410／.298。没有显示压缩特有的信息损失，但关节／EEF残差和重复组仍限制归因；不能因此宣称表示或规划已解决。保护状态仅作诊断。自然学习日志独立保存，不按该诊断筛选。

八个旧模型的冻结事实预测也已收齐：spatial两父模型H1误差／copy为.412／.421，H3为.529／.554，回位后的H7则为1.889／1.999；数据覆盖和多步动力学仍值得重点检验。这是八个TRAIN组、64条当时未见的普通日志，不能当物理控制成绩；下一轮使用这些日志后不再是留出。

准备下一轮从相同20000步父模型比较原目标、实际场景参照的变化编码、变化编码加高噪声、冻结读出和生成器后只学动作后果；均用相同新增普通日志，sample-level、不用动作target。变化编码必须在实际重规划历史与目标之间保持同一坐标，目标不得流入先验。尚无该轮性能结果，不能晋级最优配置。

- 数学上，单一状态只见一种后果时，无动作的状态查表也能拟合有限样本；同初态动作产生不同后果、且表示保留差异，才排除该退化解。共享根目标数值等价于entry项乘1/8；正确性验证不构成新颖性或控制性能证明。该轮仍只有四个物理源案例和两个从零祖先。
- 公开RoboJEPA的released-proprio轨道已完成20个共同Reach测试案例：50M／2B／8B平均进度91.00／93.40／96.12%。Push尚未齐。其留出厨房、外部预训练和绝对状态输入不同于上述候选源验证，不能据这两个不同协议的数字作同条件排名。
- 补做冻结诊断，0SGD／0新模拟：在两物理Push案例的四条既有受保护路径上，最新shared两父模型及官方共享视觉编码器，均把第1步判为图像目标距离最小。一个例子中物体距离11.57→8.78cm，我们两模型的特征距离却由0.035→0.067、0.022→0.069，官方由0.252→0.365。不同编码器距离单位不可跨模型比较。该现象证明全图特征代价不等同于物体进度，但也是参考共有问题；路径中间代价非单调本身不证明终端代价规划必败。
- 同初态首动作诊断覆盖12个新交互验证组／6厨房，每组八个实际a0及对应下一帧。分支模型动作辨识77.08%／82.29%，实际与预测图像目标代价排序相关约0.82–0.88，当前动作可见后果并非完全没学到。该指标可以靠机械臂／视角变化取得，不证明对象接触已学好，也不是成功率。RGB参考仅为mode2/action-key在已裁切图像上的适配，不能据其该项分数作正式基线排名。
- 当前较强推断是：需要区分机械臂／相机变化与任务相关物体状态，并检验后者的预测与目标排序。尚未分离“表示丢失物体信息”“信息存在但度量不合适”“接触／长程预测不准”各自贡献。共享根目标只缩小初始KL项，并没有显式约束上述能力；继续下降总体loss无法替代这些检验。详细只读诊断在EFS `runs/robocasa_geometry_review_20261110/SUMMARY.json`，受保护记录不进入训练或proposal memory。

## MetaWorld 的实际差距

在独立 LeRobot MT50 数据、从零训练、RGB＋已执行动作、无奖励、共同案例与500原生步any-success条件下，原生300 epoch基线的全50任务三种子均值为：

| 方法 | 成功率 | 六项困难任务成功数／360次模型—案例评测 |
| --- | ---: | ---: |
| SMWM | 14.20% | 0 |
| LeWM | 14.07% | 1 |
| AC-MTM | 13.37% | 0 |
| LeWM＋IDM | 9.17% | 2 |
| H-JEPA | 7.93% | 0 |
| LpWM | 4.63% | 0 |

方法的原生窗口、容量、更新数和FLOPs不同；这里是同数据／同控制评测的本地适配比较。360次结果复用120个物理案例及三个训练种子，不能算360个独立初态。容易任务中固定动作偏置也能获得高成功率，全50平均不能代替困难 manipulation 能力。

最新 causal-inverse 研究：8个模型各新增10,000更新，完成384个控制回合，无执行错误。native1／held5确定性inverse，以及uniform／high-noise flow，分别用直接inverse和正向模型筛选候选动作；所有方法、所有控制器的六项困难任务均为0/12。每组是六个物理案例×两个原训练父模型，尚无可推广的困难任务性能提升。没有据此启动更长训练。

历史25%的QueryRecurrent结果使用目标条件的专家RGB路径训练，不符合当前“只用普通事实转移、不学习专家路径”的约束；使用未来目标动作标签的旧策略同样不能作为当前有效成绩。

## 有证据支持的机制认识

- RoboCasa入口的一个源训练状态重放中，正方形视场与直接拉伸宽画面的MSE为3150／1673；统一视场后降为9.6／6.1。原生传感器状态及四步控制位移均与录制值精确一致；公开手工proprio辅助函数存在0.7m坐标原点和四元数符号差异。这是输入／接口证据，尚不是算法控制性能提升。
- 自身 latent 预测误差、inverse误差或表征秩改善，都不足以保证正确的目标排序与物体操作。不同表示的latent裸MSE也不是共同物理误差单位。
- TwoRoom同权重更换NGC代价能显著改善，说明至少部分问题在目标几何；这不证明所有任务都只缺一个距离函数。
- Cube的训练轨迹支持及查询相关检索各有收益，说明候选动作支持会限制控制；该结果付出了额外信息预算。
- 在同一批留出随机干预记录上，2,000步配对诊断中，单步响应inverse动作MSE为0.523／0.505，五步响应为0.353／0.349，零动作预测为0.455；五步模型去掉响应图像后升为0.652／0.638。观察时间改善了当前输入a₀的可辨识性，但没有转化为上述困难任务成功率提升。
- 生成式inverse的分布评分优于确定性点预测，不代表控制更强；高噪声版本尚无明确控制优势。

未来改进应以相同条件下实际困难任务成功率为主要证据。当前仍未唯一确定表示、物体／接触动力学、目标代价和长程规划各自的贡献，不能把任何单项诊断包装为已经解决问题。
