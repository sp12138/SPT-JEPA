# 关键结论

更新：2026-11-10。旧 MetaWorld 研究已结束；RoboCasa最近一轮候选研究完成但未突破，官方参考继续，入口见 [HANDOFF](../HANDOFF.md)。资源授权为dev13/dev15/dev6/dev6-2c。较优配方与来源统一保存在 [best-configs.json](best-configs.json)，原始实验记录的定位见 [归档说明](../docs/experiment-archives.md)。这里的成绩均有适用边界，不是统一公开基准的 SOTA 声明。

## RoboCasa 的新证据

- 原始TF／spatial／long三路线，六个5000步模型共240回合，Reach平均进度21.80／18.33／20.55%，Push最终进度4.59／3.68／11.36%；严格完成均0。旧历史使用发出指令，官方客户端用实际运动重建历史；旧pilot不能当发布客户端复现。
- 50M／2B450k／8B300k冻结参考的参数、编码、真实历史、缓存、下一步预测及短CEM已与公开直接调用核对通过。论文表格BF16预测与发布客户端FP16仍分别披露；RGB／本体状态输入分轨，强预训练参考不作同数据从零方法排名。
- 两个long父模型的1000步clean辅助对照把预测／copy比降至0.91／0.92，却明显削弱控制；factual／zero预测误差比为0.92／0.95，而原目标续训约0.61／0.62。改善表观预测可能同时削弱动作所提供的区别信息。这仍不是实际零动作反事实的因果证明。
- 训练实际位移与规划期望位移的语义不等价，碰撞／限幅时尤其如此。一条16步普通随机交互中，两者平移差均值16.8cm；这是单轨迹诊断，不能当全体分布。三组同用222条日志／3552自然转移，各两个原父模型、1000步续训：实际位移、发出指令、高噪声的Reach／Push平均进度为34.62／7.29%、40.27／11.00%、13.14／9.26%；零动作Push为9.09%。四个共同源物理案例上严格完成全0，指令输入改善跨父模型不稳定，未启动长训；无未来／最优动作标签。
- 旧spatial读出区域掩码不能阻止骨干ViT先混合全图。实际局部扰动在原骨干产生0.1344的区域外最大变化，而限制每层注意力后精确为0；训练／模拟环境均验证，全部原权重保留。该结构证据尚未证明控制改善。局部性与固定目标差异代价的配对实验已启动。
- 人工编码噪声与物理动力学可以在条件高斯先验中分开：学习确定性受控均值，AR残差传播解析完成。条件KL数值核对和未来编码／终端动作无梯度检查通过；下述六模型结果未显示共同控制收益。这不是物理性能或新颖性证明。
- 上述六模型现已收齐40个源闭环回合：global-spatial的uniform／support为Reach45.14／18.76%、Push9.24／34.88%；regional-spatial为32.08／13.67%、4.65／9.28%；analytic-noise为40.32／0%。严格完成全0。Support对两个global父模型的Push均有帮助，但损害Reach；24次额外方向投影也未解决取舍。无长训晋级，四个物理源案例不是40个独立案例。
- 观察到的空间局部性、低阶编码噪声传播和低latent误差，都不足以保证目标相关的物体控制。受保护的状态辅助诊断确实发生机械手接触并曾接近目标，但不能稳定完成；接触／非接触总体latent误差没有一致的大幅差距，不能据此认定物体接触已学好。
- 动作后果可辨识性实验已完成：1024条同初态八分支日志／16,384转移，六模型各新增1000步到7000，48源回合无执行错误。Uniform下旧日志／分支／共享根的Reach为41.28／38.61／35.77%，Push为6.17／9.30／10.34%。共享根加direction时Push27.29%，但两个父模型45.34／9.25%，全部严格完成仍0。未超过旧global-support的源验证Push34.88%，不晋级长训。这个1000步结果不能证明更大干预语料无用；它说明当前分支采集与entry缩放尚未转化成稳定操纵收益。
- 数学上，单一状态只见一种后果时，无动作的状态查表也能拟合有限样本；同初态动作产生不同后果、且表示保留差异，才排除该退化解。共享根目标数值等价于entry项乘1/8；正确性验证不构成新颖性或控制性能证明。该轮仍只有四个物理源案例和两个从零祖先。
- 公开RoboJEPA的released-proprio轨道已完成20个共同Reach测试案例：50M／2B／8B平均进度91.00／93.40／96.12%。Push尚未齐。其留出厨房、外部预训练和绝对状态输入不同于上述候选源验证，不能据这两个不同协议的数字作同条件排名。
- 补做冻结诊断，0SGD／0新模拟：在两物理Push案例的四条既有受保护路径上，最新shared两父模型及官方共享视觉编码器，均把第1步判为图像目标距离最小。一个例子中物体距离11.57→8.78cm，我们两模型的特征距离却由0.035→0.067、0.022→0.069，官方由0.252→0.365。不同编码器距离单位不可跨模型比较。该现象证明全图特征代价不等同于物体进度，但也是参考共有问题；路径中间代价非单调本身不证明终端代价规划必败。
- 同初态首动作诊断覆盖12个新交互验证组／6厨房，每组八个实际a0及对应下一帧。分支模型动作辨识77.08%／82.29%，实际与预测图像目标代价排序相关约0.82–0.88，当前动作可见后果并非完全没学到。该指标可以靠机械臂／视角变化取得，不证明对象接触已学好，也不是成功率。RGB参考仅为mode2/action-key在已裁切图像上的适配，不能据其该项分数作正式基线排名。
- 当前较强推断是：需要区分机械臂／相机变化与任务相关物体状态，并检验后者的预测与目标排序。尚未分离“表示丢失物体信息”“信息存在但度量不合适”“接触／长程预测不准”各自贡献。共享根目标只缩小初始KL项，并没有显式约束上述能力；继续下降总体loss无法替代这些检验。详细只读诊断在EFS `runs/robocasa_geometry_review_20261110/SUMMARY.json`，受保护记录不进入训练或proposal memory。

## MetaWorld 的实际差距

在独立 LeRobot MT50 数据、从零训练、RGB＋已执行动作、无奖励、共同案例与500原生步any-success条件下，原生300 epoch基线的全50任务三种子均值为：

| 方法 | 成功率 | 六项困难任务成功数／360次模型—案例评测 |
| --- | ---: | ---: |
| SMWM | 14.20% | 0 |
| LeWM | 14.07% | 1 |
| AC-MTM | 13.37% | 0 |
| LeWM＋IDM | 9.17% | 2 |
| H-JEPA | 7.93% | 0 |
| LpWM | 4.63% | 0 |

方法的原生窗口、容量、更新数和FLOPs不同；这里是同数据／同控制评测的本地适配比较。360次结果复用120个物理案例及三个训练种子，不能算360个独立初态。容易任务中固定动作偏置也能获得高成功率，全50平均不能代替困难 manipulation 能力。

最新 causal-inverse 研究：8个模型各新增10,000更新，完成384个控制回合，无执行错误。native1／held5确定性inverse，以及uniform／high-noise flow，分别用直接inverse和正向模型筛选候选动作；所有方法、所有控制器的六项困难任务均为0/12。每组是六个物理案例×两个原训练父模型，尚无可推广的困难任务性能提升。没有据此启动更长训练。

历史25%的QueryRecurrent结果使用目标条件的专家RGB路径训练，不符合当前“只用普通事实转移、不学习专家路径”的约束；使用未来目标动作标签的旧策略同样不能作为当前有效成绩。

## 有证据支持的机制认识

- RoboCasa入口的一个源训练状态重放中，正方形视场与直接拉伸宽画面的MSE为3150／1673；统一视场后降为9.6／6.1。原生传感器状态及四步控制位移均与录制值精确一致；公开手工proprio辅助函数存在0.7m坐标原点和四元数符号差异。这是输入／接口证据，尚不是算法控制性能提升。
- 自身 latent 预测误差、inverse误差或表征秩改善，都不足以保证正确的目标排序与物体操作。不同表示的latent裸MSE也不是共同物理误差单位。
- TwoRoom同权重更换NGC代价能显著改善，说明至少部分问题在目标几何；这不证明所有任务都只缺一个距离函数。
- Cube的训练轨迹支持及查询相关检索各有收益，说明候选动作支持会限制控制；该结果付出了额外信息预算。
- 在同一批留出随机干预记录上，2,000步配对诊断中，单步响应inverse动作MSE为0.523／0.505，五步响应为0.353／0.349，零动作预测为0.455；五步模型去掉响应图像后升为0.652／0.638。观察时间改善了当前输入a₀的可辨识性，但没有转化为上述困难任务成功率提升。
- 生成式inverse的分布评分优于确定性点预测，不代表控制更强；高噪声版本尚无明确控制优势。

未来改进应以相同条件下实际困难任务成功率为主要证据。当前仍未唯一确定表示、物体／接触动力学、目标代价和长程规划各自的贡献，不能把任何单项诊断包装为已经解决问题。
