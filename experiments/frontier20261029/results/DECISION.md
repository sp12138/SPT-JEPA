# 600 更新适应筛选：继续决定

全部 120 项端点退出码为 0；20 个模型的权重与 optimizer/scheduler 张量有限，完整与便携检查点张量完全相等，样本游标和 25,582 更新数正确。所有方法均未触发后验坍塌判据。完整逐例数值、条件 bootstrap 区间和成本见 FRONTIER-SHORT.md / JSON。

没有候选同时改善两个诊断训练种子的规划；本批全部停在 600 更新上限，不延长这组网格。该决定只说明当前配对适应预算没有足够继续依据，不是否定这些原理在所有训练预算或参数下可能有效。

有用的机制证据：

- 共享 flow 噪声使 h7 moving-block/copy 从 0.259/0.354 降到 0.172/0.224，但规划点估计各降 5 个百分点。生成运动改善不能替代规划收益；这些 P0 差值的条件 95% 区间均跨过 0，不宣称显著负效应。
- 时间差分项相对共享噪声本身仅有 +1/−1 个百分点的规划变化，没有跨种子的额外收益。
- clean-prior 的物块运动比率两个种子都改善，规划却没有一致增益。innovation-corrected 的 agent 运动也略好，但规划 +2/−2；编码可用性、预测误差与规划是不同终点。
- 运动加权在弱种子的后验重建比率由 0.190 改善到 0.139，P0 却从 53% 到 44%。不能只用重建质量筛选。
- 所有规划改变量的条件 95% bootstrap 区间包含 0；本批没有确认的正面规划赢家，未做多重检验校正。

下一轮用相同前向损失检查梯度流向：只截断 rate 的未来目标、只截断过去输入、同时截断两者，以及截断 renderer 到编码器的负面对照；原算法为共同控制。四个已有训练种子对应的 2epoch 完整状态，各只适应 600 更新。停止梯度是实验性更新规则，不再是原 KL 的全梯度优化，也不是新颖性证明。模型大小和 sample-level 依赖保持不变，没有 EMA 或额外网络。

这仍是成熟模型的短适应，尚不能证明从头训练稳定达到 89.3%。独立训练与未使用评测案例仍是任何最终性能结论的必要后续。
